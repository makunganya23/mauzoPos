# Disc Sales System

Mfumo wa Usimamizi wa Mauzo wa Bidhaa za Diski (Cutting Disc, Grinding Disc, nk)

## Technologies Used
- HTML5
- CSS3 (Glass Morphism Design)
- JavaScript (LocalStorage)
- Bootstrap 5
- Font Awesome Icons

## Features
- ✅ Ukurasa wa Kuingia (Login)
- ✅ Ukurasa wa Usajili (Register)  
- ✅ Dashibodi ya Usimamizi
- ✅ Usimamizi wa Bidhaa (Products)
- ✅ Point of Sale (POS)
- ✅ Usimamizi wa Mauzo (Sales)
- ✅ Usimamizi wa Watumiaji (Users)

## Setup
1. Clone repository hii
2. Host kwenye Netlify au service yoyote ya static hosting
3. Fungua `index.html` kwenye browser

## Demo Accounts
- Admin: admin@discsales.com / password yoyote
- Cashier: akaunti yoyote iliyosajiliwa

## Deployment
Imeandaliwa kwa ajili ya deployment kwenye Netlify kwa kutumia faili ya `_redirects` kwa Single Page Application support.
